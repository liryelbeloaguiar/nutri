# Ricardo Mendes Nutrição

Landing page profissional para apresentação de atendimento nutricional presencial e online.

## Comandos

- `npm start`: inicia o ambiente local.
- `npm run build`: gera a versão de produção.
- `npm test -- --watch=false`: executa os testes uma vez.
- `npm run lint`: verifica o código.
- `npm run format`: formata os arquivos.

## Personalização

Os textos, contatos, registro profissional, especialidades, indicadores e depoimentos ficam
centralizados em `src/app/core/site-content.ts`.

As imagens ficam em `public/`. Antes de publicar, confirme os dados profissionais e substitua
qualquer imagem demonstrativa que não tenha licença de uso adequada.
